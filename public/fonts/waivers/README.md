# Signed waiver fonts

Static Noto Sans font instances from the official Google Fonts repository
(https://github.com/google/fonts), embedded for multilingual signed documents.
Families: Noto Sans, Noto Sans Devanagari, Noto Sans Bengali, Noto Sans SC.
Variable originals were instantiated at default axes and weight 400 using
FontTools. Each font's SIL Open Font License is included alongside it.
Fonts are bundled locally; signing makes no third-party font request.
